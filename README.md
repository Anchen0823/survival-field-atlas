# 方块纪行 · Survival Field Atlas

一个可离线打开的 Minecraft Java 版玩家统计网页。下载 index.html 后直接打开，或使用 GitHub Pages 访问。

点击「导入本地 JSON」，同时选择同一玩家的统计文件和进度文件。新版存档通常放在 players/stats 和 players/advancements，旧版本位于 stats 和 advancements。只导入统计文件也可以使用排行、移动距离和明细搜索。

公开页面初始为空。浏览器在本地解析文件，不上传、不持久保存；刷新后可重新导入。进度列表排除配方解锁。游玩时间按每秒 20 游戏刻换算，距离按游戏统计的厘米换算。
